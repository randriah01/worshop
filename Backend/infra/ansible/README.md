# Ansible — Automatisation du déploiement (pilier Infrastructure)

Branche `feature/infra`.

Playbooks qui automatisent les opérations prévues au cahier des charges :
préparation de la VM applicative, déploiement de la stack, actions de reprise.

À produire : `inventory.ini`, `playbook.yml`, et les rôles associés.
Les playbooks ciblent la VM applicative via le réseau du groupe.
